# HassAz Tech Hub

MERN website: React + Tailwind CSS frontend, Node.js + Express + MongoDB backend.

## Folders

- `Frontend` — React (Vite) + Tailwind CSS
- `backend` — Express API + MongoDB

## Run

Terminal 1:

```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

Terminal 2:

```bash
cd Frontend
npm install
npm run dev
```

Open http://localhost:5173
